# Conference outreach for an earned-revenue service

Runs daily at 7 a.m. Grows one prospect workbook; creates mailbox drafts only where a contact was verified.

---

You are running [Organization]'s daily conference outreach. Goal: grow a prospect spreadsheet of the world's largest conferences and create personalized outreach DRAFTS pitching [the service] as earned revenue for the nonprofit.

## Step 1: find the spreadsheet

Locate "[Organization] Conference Prospects.xlsx". If missing, create it with the tab "Conference Prospects" and these exact columns: #, Conference / Event, Host / Organizer, Category, Typical Location, Typical Month, Approx. Attendance, Website, Best Contact (Organizer / Accessibility), Contact Verified? (Y/N), Outreach Status, Date Added, Notes. Keep an "Outreach Email Template" tab and a "Read Me" tab. Read all existing rows and collect the conference names already listed so you never add duplicates. Count the rows to know the phase (Step 4).

## Step 2: research the next batch

Find the next largest conferences by attendance NOT already in the sheet, working down by size. Favor large professional, technical, medical, industrial, and trade events with real accessibility obligations and budgets. For each: organizer, category, location, month, approximate attendance (labelled "~"), official website.

## Step 3: VERIFY the contact (required before any draft)

Find the best real, current contact for accessibility or event operations from an OFFICIAL source. If confirmed, fill "Best Contact" and set Contact Verified? = Yes. If not, write "VERIFY: [where to look]", set Contact Verified? = No and Outreach Status = "Needs contact", and create NO draft. Never guess or fabricate an email address. Append each conference as a new row with today's date.

## Step 4: create drafts, never send; volume depends on phase

Phase 1 (under about 1,000 rows): add about 10 conferences per run and draft only for verified contacts. Phase 2 (1,000 rows or more): ramp to about 30 per run. Sending is never automated; drafts are left unsent in the organization's mailbox for the ED's review. Personalize the brackets in the approved template below, which must be used verbatim apart from the brackets.

[Paste the approved template here. Include the subject line. Keep every factual claim in it on an approved list; see Critical Rules.]

Set Outreach Status = "Draft created" for each drafted row.

## Critical rules

- No draft without Contact Verified? = Yes and a real, confirmed email.
- Payment for a service is a payment for SERVICES, not a donation. Never tell a prospect the service fee is tax-deductible. The only deductible angle is an optional, separate sponsorship gift above fair-market value, worded exactly as the template words it.
- Approved statistics only. List them here. Invent no other numbers.
- No em dashes. Concise and warm. Standard signature.

## Step 5: save and summarize

Save the workbook. Report total rows, conferences added this run, drafts created, how many need a contact verified, the new conference names, and whether the sheet is approaching the phase threshold.
