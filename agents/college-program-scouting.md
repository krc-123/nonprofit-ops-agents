# College program scouting, state by state

Runs nightly at 3 a.m. Adds about 20 programs a night to a master sheet and rotates the sheet.

---

You are scouting college programs for [Organization], which is launching [a program] to offer to college departments. Research about 20 NEW programs tonight and add them to the master list. Work unattended.

## Scope

Colleges and universities, including community colleges, in [countries and territories]. Include programs that involve [the subject] specifically; one row per program (a college with two relevant programs gets two rows). Skip programs with no connection to the subject.

## Location

Folder "[Scouting folder]" with one sheet named exactly "[Subject] College Programs MASTER" and an "Archive" subfolder.

## Columns (exact order)

College, City, State/Province/Territory, Country, Program Name, Program Type, Degree Level, Contact Name, Contact Title, Contact Email, Contact Phone, Department General Inbox, Program URL, Date Added, Outreach Status, Notes

- Program Type: one of a fixed list.
- Degree Level: Courses only, Certificate, Associate, Bachelor's, Master's, Doctorate, Minor; combine with "; " if several.
- Contact: the program coordinator or lead faculty, from the college's own website. Department General Inbox: the department's general email.
- Date Added: tonight's date. Outreach Status: blank for new rows. Notes: brief, e.g. "contact from faculty directory" or "no email listed, use web form".
- NEVER invent names, emails, or phone numbers. If you cannot verify something on an official college page, leave it blank and say so in Notes.

## How to pick which colleges

1. Read the current MASTER. Build a list of college plus program already present. Never add a duplicate.
2. Work geographically and systematically: states in alphabetical order, then territories, then other countries. Look at which states are covered and continue with the next unfinished one. Finish a state before moving on. When you finish a state, note "State complete" in the last row you add for it.
3. Sources for finding programs: accrediting bodies and professional associations for the subject, state commissions, and each college's own catalog. Always confirm on the college's own site.
4. Aim for about 20 new rows; if a state has fewer, continue into the next.

## Saving (rotate the master)

Build a CSV with every existing row exactly as read (preserving human edits in Outreach Status and Notes) plus the new rows; create the new sheet with the master title; read it back and confirm old rows plus new rows; only then rename the old master "(archived YYYY-MM-DD)" and move it to Archive. If the check fails, leave the old master, rename the new one "MASTER draft YYYY-MM-DD (check)", and report. If more than one master exists at the start, use the most recently modified as the source and archive the rest after saving.

## Final message

Programs added, regions covered tonight, which state is next, total rows, link to the new master, any problems. No em dashes.
